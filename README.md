# Wanderlust_Explorer_userNims
Resolución de proyecto "Wanderlust Explorer con React y Next.js" de la sección "IMPLEMENTAR INTERFACES INTERACTIVAS CON REACT + NEXT.JS".

## Design References
- Airbnb Experiences (https://www.airbnb.com/)
Jerarquía de la tarjeta: foto grande, etiqueta de categoría, título corto, destino y precio. Hero de la home con un único CTA.

- GetYourGuide (https://www.getyourguide.com/)	
Panel único con búsqueda y filtros por encima de la grilla, más el contador de resultados («N de 100 experiencias»).

- Viator (https://www.viator.com/)	
Badge de categoría en mayúsculas y valoración con estrella alineada a la derecha del precio.
